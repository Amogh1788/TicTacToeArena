# 🎮 TicTacToe Arena

A modern JavaFX implementation of Tic Tac Toe developed by **AG Studios**.

## ✨ Features

- 🎨 Modern dark-themed UI
- ❌⭕ Two-player gameplay
- 🏆 Winner detection
- 🟨 Animated winning line
- ✨ Winning cell animation
- 🔄 Play Again option
- 🚪 Smooth screen transitions

## 🛠️ Built With

- Java
- JavaFX
- Gradle
- IntelliJ IDEA
